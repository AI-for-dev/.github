# The mark

The course argues that a coding agent is mostly the harness around the model: what goes
into its context, which skills it can load, how work is split between agents, and which
rules code enforces. The mark draws that, **four corners around a square**.

The square is the model, and the only coloured shape, because it is the part nobody here
writes. The corners are everything that is written around it, all in the ink and all the
same, since no piece of the harness matters more than the others. They do not touch: a
harness controls what goes in and out, it does not close the box. Rectangles only, at
every size, like [trysquare](https://github.com/AI-for-dev/trysquare) and
[combo](https://github.com/AI-for-dev/combo).

Every file here is generated by `tools/build-brand.py`. Edit the script, then run
`uv run --with fonttools python tools/build-brand.py`.

| file | colour | use |
| --- | --- | --- |
| `ai-for-dev-mark-light.svg` | slate + sanguine | **the mark**, light ground |
| `ai-for-dev-mark-dark.svg` | inverse ink + lifted sanguine | **the mark**, dark ground |
| `ai-for-dev-mark.svg` | `currentColor` + sanguine | inlined in a page, follows the text colour |
| `ai-for-dev-tile.svg` | slate ground | favicon, and any size below 24px |
| `ai-for-dev-avatar.png` | slate ground | the organisation avatar on GitHub, 512px |
| `ai-for-dev-lockup-light.svg` | slate + sanguine | **the brand**, light ground |
| `ai-for-dev-lockup-dark.svg` | inverse ink + lifted sanguine | **the brand**, dark ground |
| `ai-for-dev-map-light.svg` | slate + sanguine | the profile page: which repository builds which corner |
| `ai-for-dev-map-dark.svg` | inverse ink + lifted sanguine | the same, dark ground |

**The tile thickens the corners.** At 16px the mark's arms are a single pixel wide and
shimmer. The tile takes them from 5 units to 7 and leaves a little more slate around the
square, so the four corners still read as four.

**The avatar is a PNG because GitHub accepts nothing else.** It is the tile without the
rounded corners, which GitHub draws itself. To redo it, screenshot `tools/avatar.html` at
512 by 512 in a headless browser.

**The words are outlined.** GitHub shows these files through `<img>`, where no web font
loads, so live text would fall back to whatever the reader's system offers. The script
outlines them from JetBrains Mono, the same vendored file trysquare uses, and checks its
digest first.

## The palette

Slate `#232B33`, sanguine `#B4472A` (`#E2805F` on a dark ground), paper `#EEF1F3`, inverse
ink `#C9D3DB`, muted `#56616B` (`#8E9BA5` on dark) for the notes on the map.

The neutrals are trysquare's and combo's, so the three marks read as one family. The
accent is what tells them apart: brass for trysquare, verdigris for combo, and for the
organisation the sanguine of the course slides.
